## Dark and light

Solid Glass was designed for a dark interface: an even, unlit, dark grey page with smoky glass on it. There is no ambient light in dark. On a dark page it reads as a bright patch and a vignette, and uneven ground behind long text is tiring to work on.

Light uses the same names and the same edge. The glass turns white, and three very faint sources of light sit under the page. Both sets of values are at the top of the stylesheet, in `:root` and `.dark`. The switch in the corner of this site changes between them.

## Colour

The interface has no colour of its own. Primary is the ink: white on the dark page, black on the light one. Charts are drawn in greys. Hue is kept for the few things that mean something:

| Variable | What it is for |
| --- | --- |
| `--brand` | The brand. A green-teal by default, used sparingly. |
| `--status-done` | Finished. |
| `--success` | Succeeded. |
| `--status-interrupted` | Interrupted, or waiting for a decision. |
| `--destructive` | Failed, or about to delete. |
| `--link` | A link in an answer. |
| `--code-inline` | A name in running text: a file, a command, a field. |
| `--syn-*` | The four colours code is set in: keyword, string, number, name. |

To change the brand, set `--brand`, `--brand-foreground` and `--brand-muted`, once in each theme.

## Radius

Every corner is worked out from `--radius`, 0.875rem by default. Panels and code use `rounded-md`, floating things `rounded-lg`, cards and the composer `rounded-xl`, and small controls `rounded-sm`.

## Type

Body text is 14px with generous leading. The small text of the interface sits between 11 and 13px. Figures that change use tabular numerals, so they do not shift as they count.
